# velgix 🇧🇪

**Python toolkit for Belgian data: public holidays, VAT/NISS validation, postal codes.**

[![PyPI version](https://img.shields.io/pypi/v/velgix.svg)](https://pypi.org/project/velgix/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

---

## Why velgix?

Every Belgian app needs the same data again and again:

- 🇧🇪 **Public holidays** (are we open today?)
- 💼 **VAT / NISS numbers** (is this customer real?)
- 📮 **Postal codes** (which city is this?)

Instead of rewriting the same code for each project, **just install velgix**.

---

## Installation

bash
pip install velgix
